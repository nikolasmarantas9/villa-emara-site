# Villa Emara — Luxury Hospitality Website

A modern, responsive hospitality website built to showcase Villa Emara through elegant design, interactive features, and a user-friendly browsing experience.

**Live Demo:** [View Website](https://nikolasmarantas9.github.io/villa-emara-site/)

**Repository:** [GitHub Source Code](https://github.com/nikolasmarantas9/villa-emara-site)

## Overview

Villa Emara is a front-end web development project focused on creating an elegant online presence for a hospitality property. The website combines a dark visual theme, gold accents, refined typography, and responsive layouts to deliver a polished browsing experience across desktop and mobile devices.

## Features

- **Responsive Design** — Layouts adapted for desktop, tablet, and mobile screens.
- **Elegant UI** — Dark theme, gold accents, and refined typography.
- **Interactive Gallery** — Image browsing with a lightbox experience.
- **Booking Interface** — Interactive calendar and date-selection interface.
- **Multilingual Interface** — Greek, English, and Bulgarian language support.
- **Property Information** — Dedicated sections for amenities, location, and guest information.
- **Interactive Elements** — Navigation, buttons, and dynamic interface components.
